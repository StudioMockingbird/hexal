# RFC 0034 Execution Plan: Modules and Imports

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.
>
> Implements: [RFC 0034: Modules and Imports](0034-modules-and-imports.md)

**Goal:** Land multi-source in-memory compilation, file modules, aliased imports, private-by-default visibility with `export`, and per-module C/header output, per RFC 0034.

**Architecture:** Two parts. Part 1 replaces `Compile(source string)` with `Compile(sources map[string]string, entrypoint string)`, adds `CompilationResult.Files`, and splits root-module code out of `main.c` into `modules/<root>.c/.h` — with single-file programs behaving exactly as today. Part 2 adds grammar, resolution, visibility, identity, and per-module codegen for multi-module programs. Parts are sequential; each task ends green with a commit.

**Tech Stack:** Go 1.24+, existing compiler pipeline (lexer/parser/checker/generator), no new dependencies, no external tools in tests.

## Global Constraints

- **In-memory boundary.** Compiler accepts `map[string]string` + entrypoint; performs no filesystem reads, writes, discovery, symlink resolution, or working-directory lookup (AGENTS.md + RFC §Compiler input and output model). Import resolution operates only over `sources`.
- **Pure-Go tests.** No test or code may ever call an external tool — gcc, clang, or anything else (AGENTS.md). RFC 0034's "compile and link in C23-tagged tests" cannot run; the c23 files stay inert and must never be given entry points. This is a deliberate, accepted deviation; the plan's manual dev-time smoke check (Task 8, optional) is a shell command, not a test.
- **Determinism.** Never iterate a Go map for traversal, diagnostics, or artifact enumeration. Sort logical keys / canonical identities. `Files` iteration order is meaningless; consumers sort.
- **Fail-closed.** Every invalid program yields a structured diagnostic. Never emit empty results, placeholder comments, or silently omit output. No failure may be reported as `Unknown Error` when classifiable.
- **One namespace.** Import aliases share the protected name space of source types, values, functions, method owners, generic parameters, qualifiers, and other aliases. No shadowing, no redeclaration, one canonical import per module.
- **API replacement.** The former `Compile(source string)` is removed. There is one pipeline and no single-source entrypoint. `MainC`/`MainH` are derived conveniences equal to `Files["main.c"]`/`Files["main.h"]`; root module code is available only through `Files["modules/<canonical-root>.c/.h"]`.
- **Diagnostics classes.** New `Module Error` for import/dependency failures; keep `Name Error` (inaccessible names) and `Type Error` (exported-interface closure, implementation targets). Diagnostics identify file and path token for import failures; cycle diagnostics show canonical identities.
- **Docs.** Update `docs/reference.md` only after behavior stabilizes, before the RFC closes. `docs/status.md` row for 0034 moves from "Design not started" to "In progress" at start and is removed at close. Specs once closed are immutable.
- **Workbench.** Rebuild `bin/hexal-workbench.exe` and restart the running workbench at each part's end (AGENTS.md).

Routing rule — keep today's exact text, only re-home it:

3. `main.h` keeps today's header text minus user types and user prototypes (it must still `#include "modules/<root>.h"`? — no: `main.h` is included by `modules/<root>.c`; the root module header includes `main.h` at its top, so `main.c` includes only `main.h` and `modules/<root>.h`. // EncodeModuleOwner encodes each "/"-separated component as its decimal UTF-8
```go
// byte length, "_", then the source spelling. Case-preserving; no case folding.
func EncodeModuleOwner(canonicalID string) string {
	parts := strings.Split(canonicalID, "/")
	for i, p := range parts {
		parts[i] = strconv.Itoa(len(p)) + "_" + p
	}
	return strings.Join(parts, "")
}
```
