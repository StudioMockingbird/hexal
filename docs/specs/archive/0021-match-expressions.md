# RFC 0021: Match Expressions

- Kind: Feature Specification (Rust-Style RFC)
- Status: Superseded by RFC 0022; identifier retained permanently
- Created: 2026-08-09
- Superseded by: [RFC 0022: Algebraic Data Types and Match Expressions](0022-algebraic-data-types.md)

## Notice

The match-expression design originally drafted here was merged into RFC 0022
so algebraic data types and the exhaustive `match` expression are reviewed and
implemented as one feature. RFC 0022 owns the combined syntax, semantics,
narrowing, exhaustiveness, and C23 lowering.

This identifier is retained because spec numbers are permanent and are never
reused.
